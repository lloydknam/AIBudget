# 예산 AI 분석 (프로토타입)

국회 예산 심사를 돕기 위한 분석 화면의 프로토타입입니다. 메뉴 구성은 「국가예산 AI 분석시스템 안내」 책자의 6개 메뉴(홈, 한눈에 보기, 예산 탐색, 심사 참고, 조건으로 찾기, AI에게 묻기)와 부가 메뉴(삶의 질 지표)를 따릅니다. 공식 시스템과는 무관한 독립 구현입니다.

## 지금 상태
- `index.html`: 7개 메뉴가 모두 동작합니다. 브라우저로 열면 됩니다.
- 데이터는 **샘플**입니다 (`scripts/make_sample.py`가 무작위로 생성). 실제 수치가 아닙니다.
- "AI에게 묻기"는 문서 검색은 항상 동작하고, Upstage API 키를 넣으면 요약 답변을 추가로 만듭니다. 키는 저장되지 않습니다.

## 실데이터로 바꾸기
1. 열린재정 Open API 인증키를 발급받습니다.
2. `scripts/fetch_openfiscal.py`의 `ENDPOINTS`, `FIELD_MAP`, 응답 파싱을 **명세서에 맞춰** 채웁니다. (이 뼈대는 엔드포인트를 검증하지 않은 상태입니다.)
3. 국회 검토보고서·사업설명자료는 PDF를 텍스트로 추출해 `docs` 배열에 넣습니다 (쪽수 포함).
4. 실행:
   ```
   export OPENFISCAL_KEY=발급키
   python scripts/fetch_openfiscal.py --year 2027
   python scripts/build.py
   ```
5. 수집이 끝나면 `data/budget.js`가 갱신되고, 샘플 안내 문구는 `index.html` 상단에서 지웁니다.

## 구조
- `data/budget.json`: 원본 데이터 (사업별 정부안·국회확정·집행, 검토문서)
- `data/budget.js`: 화면이 읽는 전역 변수 (`build.py`가 생성)
- `index.html`: 단일 파일 화면 (외부 라이브러리 없음)

## 한계
- 조건 검색은 정해진 문장 패턴만 해석합니다.
- 심사 참고 규칙은 예시 기준(집행률 80%, 증감률 20%)이며 실제 심사 기준이 아닙니다.
- 검색은 키워드 일치 기반이라 동의어를 찾지 못합니다.
